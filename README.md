"# SubwaySurf1_5_2" <br>

This is a well-decompiled and fixed Unity project of Subway Surfers 1.5.2.<br>
这是一个地铁跑酷1.5.2反编译修复的好的unity工程.<br>

You can open this project with Unity and run it<br>
你可以使用unity打开这个项目并运行它<br>

Find the Scene folder under Asset and open LoadScene to start the game<br>
找到Asset下的Scene文件夹，并打开LoadScene启动游戏<br>

After all, the project was restored through decompilation, so there may inevitably be some bugs. Please understand.<br>
毕竟工程是反编译修复出来的，难免会有些bug，请谅解<br>
